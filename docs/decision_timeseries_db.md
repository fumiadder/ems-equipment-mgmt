# 技术决策记录 — 时序数据库选型

## 决策编号
OI-03

## 背景
系统需要存储和处理 ≥1000 个 IoT 数据点的实时采集数据，需选择合适的时序数据库。设计文档推荐 TDengine，需与 InfluxDB 做正式对比评估。

## 候选方案对比

| 维度 | TDengine 3.x | InfluxDB 3.0 |
|------|---------------|--------------|
| **写入性能** | 极高（TSBS 测试中比 InfluxDB 快 6-20 倍） | 高 |
| **查询性能** | 极高（TSBS 测试中比 InfluxDB 快 7-321 倍） | 高 |
| **压缩比** | 极高（比 InfluxDB 高 2.3-25.8 倍） | 中 |
| **SQL 兼容** | 原生 SQL 支持（学习成本低） | InfluxQL / Flux（需学习新查询语言） |
| **国产化/信创** | ✅ 国产开源，符合信创要求 | ❌ 美国公司产品 |
| **制造业案例** | CATL（宁德时代）、蔚来等大型制造业客户 | 通用 IoT 场景较多 |
| **集群扩展** | 支持分布式集群 | 企业版支持（开源版有限） |
| **降采样** | 内置连续查询（降采样/聚合） | 内含任务（Task）支持 |
| **生态/社区** | 国内社区活跃，国际社区增长中 | 国际社区成熟 |
| **运维复杂度** | 低（单二进制部署） | 中（多组件） |
| **Node.js SDK** | 官方支持 | 官方支持 |

## 性能数据（来源：TSBS 基准测试）

- **写入**：TDengine 比 InfluxDB 快 **6-20 倍**（[参考](https://tdengine.com/tdengine-oss-vs-influxdb-core-tsbs-performance-results)）
- **压缩**：TDengine 压缩比比 InfluxDB 高 **2.3-25.8 倍**
- **查询**：TDengine 查询速度比 InfluxDB 快 **7-321 倍**
- **CATL 案例**：宁德时代 10000+ 生产设备、100 万+ 数据采集点、日增 1000 万条时序数据，从 InfluxDB 迁移到 TDengine（[参考](https://tdengine.com/battery-manufacturing-catl-chooses-tdengine-over-influxdb-for-millions-of-industrial-devices/)）

## 决策结果

**推荐 TDengine 3.x**

### 理由

1. **性能碾压级优势**：在 TSBS 标准测试中全面超越 InfluxDB，写入快 6-20 倍、查询快 7-321 倍、压缩比高 2.3-25.8 倍
2. **制造业验证**：CATL（宁德时代）等头部制造业客户已大规模使用，证明在制造业 IoT 场景的可靠性
3. **SQL 兼容**：开发团队无需学习新查询语言，降低学习成本
4. **信创合规**：国产开源产品，满足国内大型制造业的合规要求
5. **存储成本**：高压缩比意味着更低的存储成本，对于 2000+ 设备长期运行数据非常重要
6. **降采样内置**：内置连续查询支持自动降采样，适合 OEE/MTTR/MTBF 的多时间粒度计算

### 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 国际社区相对较小 | 国内社区活跃，官方技术支持到位 |
| 部分高级功能需企业版 | 开源版已满足本项目需求（写入、查询、降采样、集群） |
